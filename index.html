Hermes Browser Panel

A lightweight, extensible panel for the Hermes Agent that brings web browsing capabilities directly into your chat interface.

What is Hermes Browser Panel?

The Hermes Browser Panel is an embedded Chromium-based browsing panel that integrates seamlessly with the Hermes Desktop App, allowing users to interact with web content without leaving their chat environment. It provides secure, sandboxed execution and exposes browsing capabilities as tools for the Hermes Agent.

Tested Browsers

Currently tested with Google Chrome 155.0.8059.39 on Linux.

Planned testing includes Chrome and Brave on both Linux and Windows.

Long‑term goal: theoretical integration with all Chromium‑based browsers.
